About RayVo Studio

One team, four ways to work with us

RayVo Studio is a production and technical solutions company for live events. On an event, we handle production: sound, lighting, equipment, installation, programming and operation. In a club or public venue, we install, modify or upgrade an existing set-up. On a show, we design the lighting and write the programming. And for a one-off need, we rent sound, lighting and backline equipment. Four ways to work with us, one technical know-how.

  • Event production
  • Installation
  • Design & programming
  • Rental
  • Sound & lighting
  • Technical support
